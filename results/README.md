# Resultados

Os arquivos brutos das simulações devem ser gravados em `results/raw/`, pasta
ignorada pelo Git. Cada execução produz um `.npz` com snapshots, velocidades,
diagnósticos e metadados suficientes para identificar a configuração utilizada.

Somente resumos pequenos e resultados selecionados devem ser versionados neste
diretório. Figuras e GIFs destinados à apresentação ficam em `figures/`.
